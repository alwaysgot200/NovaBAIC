## 1. 需求

在悬浮菜单「以图找图」功能中新增**图片拾取器**：

1. 不去相册选图，而是**直接在当前屏幕上交互式拾取一个区域**（方形 / 圆形），
   松手即抓得该区域图片，作为以图找图的模板；
2. 以此模板在当前屏幕以图找图；
3. 找到后显示**找到区域的框、中心点位置及坐标**。

## 2. 现状与差距

| 项 | 现状 | 差距 |
| --- | --- | --- |
| 模板来源 | 仅系统相册选图（`PickVisualMedia`） | 缺屏幕区域拾取 |
| 选区交互 | `RpaVisionScreen.RoiDragBox` 仅矩形、仅编辑器内裁剪模板 | 缺圆形；缺以图找图浮层内的拾取 |
| 结果展示 | 绿色命中框 + 白十字中心 + 底部结果卡（中心像素/比例/得分） | 框上有中心点，但**屏幕上不直接显示坐标**；用户要求"框 + 中心点 + 坐标"同屏可见 |
| 匹配引擎 | `RpaTemplateMatcher`（多尺度 matchTemplate，**已支持 alpha 掩膜**：`CvTemplateOps.templateFromBitmap` 检测透明像素自动提取 alpha 作 mask） | 无需改动，圆形掩膜模板天然可匹配 |

关键事实：透明 Activity 的窗口不消费的触摸**不会透传**给下层 App（不同窗口），
所以拾取交互必须在本页自己的画布上完成——「冻结帧拾取」是唯一既直观又准确的形态。

## 3. 交互设计

### 3.1 流程（状态机）

```
主卡（模板区）──[屏幕拾取]──► CAPTURING 自隐抓帧（复用现有 captureFrame，含报因）
                                │ 成功
                                ▼
                        SELECTING 冻结画布（抓帧铺满全屏，画面与下层 App 无缝）
                        ┌─ 形状切换：方形 | 圆形
                        ├─ 拖拽画选区（见 3.2）
                        ├─ [使用此区域] / [取消]
                        └─ 选区实时预览尺寸（px）
                                │ 使用此区域
                                ▼
                        CROPPING（IO 线程裁剪；圆形做透明掩膜）
                                │
                                ▼
                        回主卡：模板预览更新（可先调阈值/灰度）→ 用户点「查找」
                        → 命中框 + 中心点 + 坐标 chip
```

- **冻结帧而非实时框选**：先抓帧再在冻结帧上框选，「所见即所得」——选区与像素
  来自同一帧，不受画面变化影响；且抓帧内容 == 下层 App 当前画面，进入/退出
  拾取模式视觉无感（与现有自隐抓帧一致，顶部提示条保留）。
- 拾取入口按钮放在主卡「选择图片」旁：**「选择图片」「屏幕拾取」**并排
  （`OutlinedButton` 双按钮），其余控件（阈值/灰度/查找）在拾取模式中禁用。
- 拾取得到的模板走与相册选图**完全相同的后续链路**（写
  `cacheDir/rpa/quickfind/selected.png` → `templateFile` 状态 → 查找）；
  RPA 编辑器拾取回填（`RpaPickRequest` / `applyPick`）同样可用屏幕拾取的模板，
  无特殊分支。
- 取消/失败报因沿用现有 error 文案与 Shizuku / 录屏授权入口，**绝不静默**。

### 3.2 选区手势（已定版：决策 A）

| 形状 | 手势 | 说明 |
| --- | --- | --- |
| 方形 | 单指对角拖出矩形 | 与 `RoiDragBox` 同款心智；矩形四边可再拖调整 |
| 圆形 | 按下点为圆心，拖出半径，松手成圆 | 已定版；圆上显示半径柄可再调 |

两种形状均实时显示选区尺寸（px）；选区小于 `MIN_TEMPLATE_SIDE`（8px）时
「使用此区域」置灰并提示。

### 3.3 圆形裁剪语义（已定版：决策 B）

**外接方形裁剪 + 圆外像素置全透明（alpha=0）**，PNG 保留 alpha 通道。

- 匹配端零改动：`templateFromBitmap` 检测到透明像素即提取 alpha 为 mask，
  `matchAtScale` 已走掩膜匹配——圆形图标/按钮的四角背景不会污染得分；
- 灰度 / 彩色两种模式下掩膜均生效（mask 与通道数独立）。

### 3.4 结果展示增强（需求 3）

在现有基础上补「坐标同屏可见」：

1. 保持绿色命中框（半透明填充 + 3dp 描边）+ 白十字中心 + 中心圆点；
2. **新增中心坐标标签**：十字旁浮一枚深色圆角小 chip：`(123, 456)`，
   贴边时自动内收不出屏；显示抓帧像素坐标；
3. **新增命中框尺寸标签**（可选，框右上角）：`96×64`；
4. 底部结果卡保留（中心像素 / 归一化比例 / 得分 / 抓帧时刻 / 复制按钮），
   语义不变。

## 4. 技术方案

### 4.1 坐标映射（纯函数，JVM 可测）

冻结画布 = 抓帧 bitmap 铺满窗口（`Image` + `ContentScale.FillBounds`）。
选区在 view 坐标 → 帧像素坐标，x/y **各自独立缩放**（复用
`RpaQuickFindGeometry` 口径，与 §6.5 一致，覆盖状态栏 / 刘海 / 分屏）：

```kotlin
// RpaQuickFindGeometry 新增（示意）
fun frameRect(view: RpaQuickFindBox, frameW: Int, frameH: Int, viewW: Int, viewH: Int): RpaBounds?
fun circleBoundingSquare(centerX: Float, centerY: Float, radius: Float): RpaQuickFindBox
```

- 反向映射结果钳位到帧边界；
- 圆形取外接正方形为裁剪矩形，圆内判定 `dx²+dy² <= r²`。

### 4.2 裁剪与掩膜（IO / Default 线程）

1. `Bitmap.createBitmap(frame, l, t, w, h)` 裁出（矩形直接用；圆形裁外接方）；
2. 圆形：把圆外像素 `Color.TRANSPARENT`（`Canvas + drawCircle(PorterDuff.CLEAR)`
   或逐像素，取前者）；
3. PNG 100% 压缩写 `cacheDir/rpa/quickfind/selected.png`（与相册选图同落点、
   同生命周期，退出即清）——**不新增持久化点**；
4. 复用 `writeTemplateFile` / `decodeTemplate` 既有校验口径（最小边 8px）。

## 5. 双模与报因自检（AGENTS.md §4.5）

| 问题 | 回答 |
| --- | --- |
| a11y 关闭还能走通吗？ | **能**。本功能感知面只依赖抓帧（Shizuku / MediaProjection 阶梯，`FrameSource` 同源），与 a11y 无关，无 a11y 硬前置。 |
| 执行面？ | 不涉及注入，无执行面。 |
| 失败报因？ | 抓帧失败沿用现有三类报因（`REASON_CAPTURE_UNAVAILABLE` / `REASON_BLANK_FRAME` / 通用）+ Shizuku / 录屏授权入口；裁剪失败 Toast 报因；选区非法置灰按钮并提示。 |
| 静默失效？ | 无。每个失败分支都有可见文案或按钮态。 |

## 6. 边界与风险

| 风险 | 对策 |
| --- | --- |
| 抓帧后画面变化 | 结果属于抓帧瞬间（顶部提示条已声明）；查找也用同一时刻帧 |
| FLAG_SECURE / 息屏黑帧 | 现有空白帧质检报因，提示换页面或 Shizuku |
| 圆形掩膜对小目标失效 | 圆外透明像素占比大时得分仍由圆内像素决定（掩膜匹配）；不设额外分支 |
| 选区超出帧边界（状态栏/导航栏映射） | 逆向映射钳位；状态栏区域由系统抓帧涵盖，无额外偏移 |
| 极小选区 | 8px 下限（与 `MIN_TEMPLATE_SIDE` 一致），按钮置灰 + 提示 |
| 横屏 / 分屏 | x/y 独立缩放已覆盖（几何单测守护） |
| 内存 | 屏幕拾取模板天然 ≤ 一屏（≤ 2000px 阈值内），无采样降级需求 |

## 7. 测试与验收

1. **JVM 单测**（`:app:testDebugUnitTest`）：
   `frameRect` 正反向映射一致、钳位、圆外接方、非法输入全 null/0；
   圆形掩膜纯逻辑（圆内不透明 / 圆外透明）。
2. **编译门禁**：`:app:compileDebugKotlin` → `:app:assembleDebug` →
   `tools/check-license-headers.sh`。
3. **模拟器冒烟**（`Galaxy_Intel_API_36`）：
   - 悬浮球 → 更多 → 以图找图 → 屏幕拾取 → 方形框选 → 自动查找 →
     命中框 + 中心点 + `(x, y)` chip 可见，底部卡片数值一致；
   - 切圆形拾取圆按钮 → 查找命中（掩膜得分合理）；
   - 取消拾取、超小选区、黑帧报因、退出清理缓存、拾取回填 RPA 步骤各走一遍；
   - `adb logcat -d | grep -E "FATAL|AndroidRuntime"` 必须为空。

## 10. 已确认决策（2026-10-30 owner 定版）

- **A. 圆形手势**：**圆心拖半径**——按下=圆心、拖出半径、松手成圆，圆上半径柄可微调。
- **B. 圆形裁剪语义**：**外接方 + 圆外透明掩膜匹配**——四角背景不污染得分。
- **C. 拾取完成后**：**回主卡手动查找**——确认选区后回主卡，可先调阈值/灰度再点「查找」。
